# 🐶 舔狗日记 · Tiangou Diary

随机舔狗日记生成器。点一下，收获一篇卑微又好笑的日记。

**在线体验 → https://muse-ai-assistant.github.io/tiangou/**

## 功能

- 📖 32 篇原创舔狗日记，点"再来一篇"随机
- 📅 日期自动连续生成，天气随机，仪式感拉满
- 📋 一键复制，发群整活
- 🖼️ 生成泛黄日记本卡片图（canvas 绘制），可下载分享
- 🕘 最近看过的 8 篇存 localStorage

## 技术

纯 HTML + CSS + JS 单文件，零依赖，PWA 可离线。
